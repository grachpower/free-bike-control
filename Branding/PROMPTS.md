# FreeBikeControl branding

Generated using the built-in image_gen tool. The selected master icon and transparent logo are stored in this directory. Xcode assets use a 1024px iOS icon, the standard macOS sizes, and the transparent BrandLogo. App header typography remains native SwiftUI text.

## Initial icon prompt

Use case: logo-brand. Asset type: production iOS/macOS app icon for FreeBikeControl, a cycling controller bridge. Create ONE finished square icon, full bleed opaque 1024x1024, not a presentation or mockup. Deep near-black graphite/navy background #0B0F13, subtle polished tonal depth. Center a unique clean geometric cycling brand mark: two bold lime #BFF251 circular bicycle wheels connected by a minimal angular bicycle frame, integrated subtle plus and minus control motifs in the wheel centers. Cohesive original compact silhouette, confident premium sports technology identity. Mark occupies about 65% of square with generous safe margins. Crisp vector-like rounded strokes and strong readable geometry at 32px. Flat restrained lighting, no chrome, no neon bloom, no extraneous ornaments. No text, letters, watermark, border, outer rounded corners, device mockup, or multiple variants. Background must reach all four corners; platform supplies icon mask.

## Transparent logo prompt

Use case: background-extraction / logo-brand. Edit target: the attached FreeBikeControl icon. Produce its standalone logo mark on genuinely transparent background. Keep the same exact bold lime bicycle design, round wheels, frame, handlebar, saddle and strokes; remove the dark background entirely including inside all holes. Swap the two control symbols so LEFT wheel contains minus and RIGHT wheel contains plus, matching the actual controllers. The logo mark is flat solid lime #BFF251, clean crisp antialiased edges, no shadows or glow. Tight generous transparent padding around mark about 5% rather than the icon's large padding. No text, no additional elements. Transparent PNG for reuse in native application header.

## Refinement

Clean smooth rounded vector-style edges, flat lime #BFF251, no stray particles or texture. Preserve bicycle geometry with left minus and right plus. Transparent logo; opaque graphite #0B0F13 full-bleed square icon with no text or outer rounded corners. Resized with sips for Xcode asset slots.
